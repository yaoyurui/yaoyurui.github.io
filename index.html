关于体验与源码

在线体验需要注册账号或填写 API Key 吗？

不需要。公开页面提供独立交互演示，可以查看模拟样本、规则依据、真实调用快照，并填写仅保留在当前页面的演示复核记录，不会上传你的输入。

网页会实时调用模型吗？

不会。为了避免免费模型高峰期不可用影响查看，网页展示已验证的真实模型回答快照，并明确标注。完整的本地工具支持真实模型调用，需要你自行配置有效的模型密钥。

源码包包含什么，怎么启动？

包括 Python / JavaScript / PowerShell 源码、模拟标准、模拟 Excel 和自动化测试，不含真实密钥、加密密钥或运行数据库。解压后安装 Python 3.10+，运行 python app.py --open；完整步骤见包内说明。下载源码说明 →

这个项目有哪些验证边界？

已完成50份模拟文档的检索验证、75项离线检查，并核验过一次真实 GLM 调用返回 ok。本轮拒绝12条构造的引用异常回答，不代表模型幻觉发生次数。尚未完成真实用户任务试用、耗时对照或真实企业标准验证，不将原型测试结果作为产线效果或效率提升数据。详细记录见项目案例页。
